# 🛡️ SafeRoute Nepal

**SafeRoute Nepal** is a hazard-aware navigation and emergency safety platform developed for the **DevRumble 2026 competition**.

The system helps users identify verified hazards, report dangerous situations, locate nearby safe places, and compare available road routes to find a **lower-risk route**.

> SafeRoute does not claim that any route is completely safe. Route recommendations are based on currently available verified hazard information and conditions may change.

---

## 🚨 Problem

During disasters and emergency situations such as:

- Landslides
- Floods
- Fires
- Road blockages
- Earthquake damage

normal navigation systems usually focus only on distance and travel time.

They may not consider active hazards affecting roads.

SafeRoute Nepal adds hazard information into the navigation process.

---

## 💡 Solution

SafeRoute Nepal provides:

### 🗺️ Live Safety Map

Displays:

- User's current GPS location
- Verified hazards
- Safe locations
- Hazard severity
- Hazard confidence level

Only hazards verified by an administrator are displayed publicly.

---

### 🧭 Lower-Risk Route Finder

Users can:

1. Detect their current location
2. Search for a destination
3. View multiple route alternatives
4. Compare route risk
5. Select the recommended lower-risk route

Routes are evaluated using:

- Hazard severity
- Hazard confidence
- Distance of hazards from the route
- Verified hazard information

---
